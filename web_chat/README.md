# ryna / らいな 公開チャット版

たあたる式AIの会話実験人格「ryna / らいな」をブラウザで動かす、GitHub Pages向けの静的サイト。

## 含まれる処理

- sin波による感情状態の変化
- 入力中の最大インパクト語による感情移動
- 共起モデルによる関連語候補
- 感情ゾーン別マルコフ連鎖による返答生成
- 入力からランダムに選んだ最大3語を5ターンだけ保持する短期話題記憶
- 入力語の平均感情座標を受けて独立したsin波で動く、相手の推定感情表示
- `自分の感情 x 相手の推定感情` の16組み合わせごとに学習した短文返答の選択

旧会話学習は隔離済みで、現在の `data/model-data.js` は感情座標と新しい自他感情会話モデルを同梱する。サイト上で追加学習は行わず、
自分の感情状態、相手の推定感情状態、短期話題記憶、会話表示履歴だけを各訪問者の `localStorage` に保存する。
返答は現在の自分と相手のゾーンに対応する教材から、入力内容の近い例を優先して選ぶ。

らいなは感情表現の強い実験人格であり、荒い言葉や重い反応を返す場合がある。
公開ページにはこの旨を表示している。会話入力と表示履歴は閲覧者のブラウザ内だけで扱い、
公開ページから外部サービスへ送信しない。

## ローカル確認

`index.html` を直接開いても動作する。GitHub Pagesと同じ配信環境で確認したい場合は、
簡易サーバーを使う。

```powershell
cd web_chat
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。

## GitHub Pages

このフォルダの内容をリポジトリの公開対象に置き、GitHub Pages の公開元を設定する。
単独リポジトリにする場合は、`web_chat` の中身をリポジトリ直下へ置けばよい。

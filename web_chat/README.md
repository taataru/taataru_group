# たあたる式AI 公開チャット版

Python版の返答生成部分をブラウザで動くように移植した、GitHub Pages向けの静的サイト。

## 含まれる処理

- sin波による感情状態の変化
- 入力中の最大インパクト語による感情移動
- 共起モデルによる関連語候補
- 感情ゾーン別マルコフ連鎖による返答生成

学習済みモデルを `data/model-data.js` のスナップショットとして同梱している。サイト上で追加学習は行わず、
感情状態と会話表示履歴だけを各訪問者の `localStorage` に保存する。

## ローカル確認

`index.html` を直接開いても動作する。GitHub Pagesと同じ配信環境で確認したい場合は、
簡易サーバーを使う。

```powershell
cd web_chat
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。

## GitHub Pages

このフォルダの内容をリポジトリの公開対象に置き、GitHub Pages の公開元を設定する。
単独リポジトリにする場合は、`web_chat` の中身をリポジトリ直下へ置けばよい。
